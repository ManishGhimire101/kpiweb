# Features & User Workflows

## Core Feature List
- User roles: Admin, Staff, Teacher, Student, Parent (extendable)
- Library resource management: add, edit, remove books and files
- Notices and announcements management (static pages and dynamic posts)
- File uploads and categorized storage under `uploads/`
- Simple authentication hooks ready for integration
- Program/course pages and staff listings in `public/`

## User Workflows

Admin
- Manage users, approve uploads, configure site settings
- View system logs and run DB maintenance tasks

Teacher/Staff
- Publish notices, manage resource listings, upload materials
- Review student submissions (if assignment module added)

Student/Parent
- View notices, download resources, check program pages
- Upload assignments or forms (if enabled)

## Features to Add for Full Portal
- Role-based dashboards with personalized views
- Attendance and gradebook modules (School/College portals)
- Course registration and degree audit (College portal)
- Searchable, versioned document repository (IMS)
- Notifications (email, SMS) and scheduling integration

## UX Principles
- Keep pages simple and accessible with the existing static assets
- Use responsive layout for mobile-first access
- Prioritize minimal training for non-technical staff
